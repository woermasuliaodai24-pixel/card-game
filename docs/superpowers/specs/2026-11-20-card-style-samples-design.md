# 卡牌与 Boss 展示风格样图设计

## 目标

生成四张可直接横向比较的概念样图，用于选择卡牌游戏的基础视觉方向。项目独立于现有神庙游戏，不复用其题材、世界观或资产。

本轮只做视觉方向探索，不作为最终可直接上线的 UI 或游戏资产。

## 比较方法

- 每种风格生成一张独立横版样图。
- 每张样图同时包含一张普通竖版卡牌和一张更具压迫感的 Boss 展示卡。
- 四张图使用相同的原创角色主题、信息层级和构图比例，仅改变美术语言、材质、配色与装饰。
- 不依赖小字判断风格；信息区以图标、数字占位和清晰留白为主。

## 统一内容

- 普通卡主题：原创的年轻守卫型角色，持短剑，具有微弱星火能量。
- Boss 主题：原创的巨大深渊兽，轮廓清晰，有角与发光核心。
- 普通卡预留：费用、角色名称、攻击、防御、技能描述区。
- Boss 展示预留：名称、阶段标记、大型生命值区域、两个技能图标区。
- 画面背景保持简洁，只服务于卡牌轮廓与材质展示。

## 四种视觉方向

### A. 经典奇幻

- 手绘奇幻插画质感。
- 古铜、深蓝与琥珀宝石配色。
- 雕刻金属边框、轻微磨损、对称纹章。
- Boss 卡采用更厚重的冠形框体和暗金生命值结构。

### B. 哥特暗黑

- 高对比暗色插画，带秘仪和宗教建筑感，但不引用现实宗教符号。
- 黑铁、骨白、暗红配色。
- 尖拱、荆棘、蜡封与抽象符文装饰。
- Boss 卡强化不对称尖角和猩红核心，形成危险感。

### C. 明亮动漫

- 清晰赛璐璐角色、锐利轮廓和高饱和能量特效。
- 银白、天蓝、金黄配色。
- 简洁几何框、圆角信息模块和醒目的属性图标。
- Boss 卡使用放大的角色半身构图、阶段徽章和宽幅生命值区。

### D. 科技全息

- 科幻收藏卡与战术 HUD 融合。
- 碳黑、青色、紫红霓虹配色。
- 透明玻璃层、发光线路、六边形和扫描线细节。
- Boss 卡使用宽幅全息面板、警报标记和分段生命值条。

## 输出规格

- 数量：4 张。
- 每张：横版构图，普通卡在左、Boss 展示在右。
- 用途：预览与方向选择。
- 图像中不出现品牌、现有 IP、签名或水印。
- 避免密集小字、随机乱码、界面裁切和过度复杂背景。
- 首轮生成结果保留在预览位置；用户选定方向后再制作项目内正式资产。

## 验收标准

- 一眼可区分四种风格。
- 普通卡与 Boss 展示在同一风格内具有明显家族一致性。
- 四张图的内容和信息层级足够一致，可公平比较。
- 卡框、角色插画和信息区域均清晰可见。
- 用户能够明确选择一个方向，或指出希望混合的两个方向。
