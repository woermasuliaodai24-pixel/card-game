# 设计想法

用于记录尚未进入实现范围的点子。想法可以大胆，但必须说明它改变了玩家的哪个决策，以及与时间机制的关系。

复制下面的模板新建一份 Markdown 文件：

```markdown
# 想法：<一句话名称>

- 日期：
- 提出者：
- 状态：草稿 / 讨论中 / 已采纳 / 搁置

## 机制

这个想法具体如何运作？

## 玩家决策

玩家因此需要在什么之间做取舍？为什么不是单纯提高数值？

## 与时间的关系

它如何利用、改变或挑战“时间代替能量”的核心规则？

## 风险

可能破坏平衡、增加理解成本或与其他机制冲突的地方。

## 下一步

需要原型、试玩或设计评审吗？
```
