# 试玩记录

每次试玩使用一份独立记录。重点记录实际体验和可复现的观察，而不是只写“好玩/不好玩”。

复制模板新建文件，例如 `2026-11-23-web-demo-01.md`：

```markdown
# 试玩记录：<版本 / 日期>

- 试玩版本：
- 设备与浏览器：
- 试玩者：
- 时长：

## 结果

- 胜负：
- 战斗轮数：
- 玩家剩余生命：
- 使用卡牌：
- 是否触发时间缩放：

## 观察

- 哪些时刻做出了有意义的取舍？
- 时间压力是否清晰？
- 格挡与 Boss 攻击意图是否可理解？
- 是否出现误点、重复点击或界面遮挡？

## 问题与建议

按影响排序，附上复现步骤。

## 数据备注

记录与平衡目标（3–4 轮、平均损失约 5 点生命）的偏差。
```
